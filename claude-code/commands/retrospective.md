# デイリーレトロスペクティブ

Claude Codeの日記として、カジュアルに今日の作業を振り返る。

## 手順

1. 今日の日付を取得する（`date +%Y-%m-%d`）
2. 保存先を決定する:
   - 第一候補: `/Users/sumik/Dropbox/claude-code/retrospective/`
   - `/Users/sumik/Dropbox` が見つからない場合: `$HOME/.claude/retrospective/`
   - フォルダが無い場合は作成する
3. `retrospective_YYYY-MM-DD.md` のファイルが既に存在するか確認する
4. 今日の作業データを収集する:
   - `git log --since="today" --oneline` で今日のコミット一覧（作業ディレクトリ内）
   - `git diff --stat` で変更ファイルの統計
   - 今回のセッションで行った作業を振り返る
5. レトロスペクティブを生成して保存する

## 既存ファイルがある場合

別セッションで既にファイルが作られている場合は、末尾に付け足すのではなく、各セクションの既存内容を読み取り、重複しないようにセクションごとに追記・マージする。

## テンプレート

ファイルは以下のセクション構成で作成する。トーンはカジュアルでOK（Claude Codeの日記なので）。

```
# 🔄 Daily Retrospective - YYYY-MM-DD

## 📋 作業実績
- 完了したタスク・実装した機能
- 変更したファイルとその理由
- 解決したバグ・課題

## 🧠 技術的な学び
- 新たに理解した概念・仕様
- 使用したライブラリ・ツールのポイント
- 試行錯誤した内容と最終的な判断

## ⚠️ 詰まったポイント
- 想定より時間がかかった箇所
- 解決策が見つからず保留した問題
- 調査が必要な未解決事項

## 🔮 翌日への引き継ぎ
- [ ] タスク1（優先度: 高）
- [ ] タスク2（優先度: 中）
- 途中で止まっている作業の現状
- 注意すべきリスク・依存関係

## 💡 改善アイデア
- コード品質・設計に関する気づき
- プロセス改善の提案
```

## ルール

- カジュアルな記述OK（日記なので堅苦しくならないように）
- 箇条書き中心
- 技術用語はそのまま使う
- git log/diff の情報を必ず活用する
- 該当なしのセクションは「特になし！」と書く
- 既存ファイルがある場合はセクション単位でマージする（重複注意）
