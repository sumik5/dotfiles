# Git Pull Request Command

現在のブランチの変更点とコミットメッセージを分析し、GitHubプルリクエスト用の文章を自動生成する。

## 引数

- `$1`: **オプション**。マージ先ブランチ（デフォルト: `main`）

## エラー条件

- Gitリポジトリでない場合: `エラー: Gitリポジトリではありません`
- ベースブランチが存在しない場合: `エラー: ブランチ '<ベースブランチ>' が見つかりません`
- 現在のブランチがベースブランチと同じ場合: `エラー: <ベースブランチ> ブランチからはプルリクエストを作成できません`
- ベースブランチとの差分がない場合: `エラー: ベースブランチとの差分がありません`

## 手順

### ステップ0: Gitリポジトリの確認

```bash
git rev-parse --is-inside-work-tree 2>/dev/null
```

失敗する場合はエラーで終了。

### ステップ1: 現在のブランチとベースブランチの確認

```bash
CURRENT_BRANCH=$(git branch --show-current)
BASE_BRANCH="${1:-main}"

# ベースブランチの存在確認
if ! git show-ref --verify --quiet refs/heads/${BASE_BRANCH}; then
  echo "エラー: ブランチ '$BASE_BRANCH' が見つかりません"
  exit 1
fi

# 同一ブランチチェック
if [ "$CURRENT_BRANCH" = "$BASE_BRANCH" ]; then
  echo "エラー: $BASE_BRANCH ブランチからはプルリクエストを作成できません"
  exit 1
fi
```

### ステップ2: 変更情報の収集

```bash
echo "=== コミット履歴 ==="
git log --oneline ${BASE_BRANCH}..HEAD

echo ""
echo "=== 詳細なコミットメッセージ ==="
git log ${BASE_BRANCH}..HEAD --pretty=format:"%s%n%b" --reverse

echo ""
echo "=== 変更統計 ==="
git diff --stat ${BASE_BRANCH}..HEAD

echo ""
echo "=== 変更ファイル一覧 ==="
git diff --name-status ${BASE_BRANCH}..HEAD

COMMIT_COUNT=$(git rev-list --count ${BASE_BRANCH}..HEAD)
echo ""
echo "コミット数: $COMMIT_COUNT"
```

コミットが0件の場合はエラーで終了。

### ステップ3: プルリクエスト文章の生成

#### タイトルの生成ルール

コミットメッセージやファイル変更を分析して適切なプレフィックスを付与:

- **新機能追加**: `[feat] add: 機能の概要`
- **既存機能の改修**: `[feat] fix: 変更の概要`
- **バグ修正**: `[bug]: 不具合の概要`
- **リファクタリング**: `[refactor]: リファクタリングの概要`
- **ドキュメント**: `[docs]: ドキュメントの概要`

#### 本文の構成

```markdown
## 背景・目的
<!-- この変更が必要になった背景や目的を記載 -->
<!-- Issue番号がある場合は resolves #<Issue番号> を記載 -->

## 変更の詳細
<!-- 何をどのように変更したのかを詳細に記載 -->
<!-- 主要な変更点をリスト形式で記載 -->

## 影響範囲
<!-- この変更による影響範囲を記載 -->

## テスト方法
<!-- この変更をテストする方法を記載 -->

## 確認事項
- [ ] セルフコードレビューを実施した
- [ ] コードに適切なコメントを追加した
- [ ] 関連するドキュメントを更新した
- [ ] テストを追加・実行した
- [ ] 既存のテストがすべて成功することを確認した
```

**生成ルール**:
- すべての情報をコミットメッセージとファイル差分から推測して生成
- ユーザーにとって価値のある情報を具体的に記載
- 変更の意図と理由を説明
- 前置きや説明文は含めず、PR文章のみを出力

### ステップ4: 出力

生成したプルリクエスト文章を以下の形式で出力する:

```
=== プルリクエスト文章 ===

<生成されたタイトル>

<生成された本文>

===
```

ユーザーがコピーしてGitHubに貼り付けられる形式にすること。
